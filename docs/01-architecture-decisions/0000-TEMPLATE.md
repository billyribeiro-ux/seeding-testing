# ADR 0000 — Template

> Copy this file to `NNNN-your-slug.md` (next free number) and fill it in.

- Status: Proposed | Accepted | Deprecated | Superseded by ADR-XYZ
- Date: YYYY-MM-DD
- Deciders: @people who actually decided
- Tags: short, lowercase, comma-separated

## Context and Problem Statement

One short paragraph. What's the situation? What's the question?

## Decision Drivers

Bullet list. The constraints / goals / values that guided the decision.

## Considered Options

1. Option A — one sentence describing it
2. Option B
3. Option C

## Decision Outcome

Chose **Option X** because …

Two or three sentences. Then bullet the *positive* properties of the
choice.

## Consequences

- **Positive:** what we gain.
- **Negative:** what we lose, *explicitly*. (An ADR with no
  negatives is wishful thinking.)
- **Mitigations:** how we plan to live with the negatives.

## Notes

When we'll re-evaluate. Related ADRs. Links to RFCs / issues / PRs that
preceded this decision.
