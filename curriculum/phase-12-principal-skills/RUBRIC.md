# Phase 12 — Rubric

The non-code rubric. Read this and ask: "could I find one example of each
in my work last quarter?"

| Dimension | Beginner (1) | Competent (3) | Principal (5) |
|---|---|---|---|
| **ADRs** | Doesn't write them | Reviews them; occasionally writes one | Authors them whenever a non-trivial decision happens; cites them in PR review |
| **RFCs** | Writes code first, explains later | Writes RFCs for medium changes | Distinguishes when to write one; runs review meetings that end in a decision |
| **Code review** | Comments on style; misses architectural drift | Catches bugs, suggests improvements | Teaches without crushing; asks "should this be an ADR?"; pairs when the diff is too big to comment |
| **Incident response** | Adds to the chaos | Capable DRI for a small incident | Calm under pressure; runs blameless postmortems; sees trends across incidents |
| **Mentoring** | None or ad-hoc | Has a weekly mentee | Mentors at the right altitude; ends each session with explicit follow-ups |
| **Sponsorship** | None | Recommends people for work | Spends reputation deliberately; advocates in calibrations |
| **System design** | Codes first, designs later | Sketches before coding | Runs the conversational arc; capacity math; designs for failure |
| **Direction-setting** | Implements what's asked | Suggests alternatives | Frames the problem the team should solve next quarter |
| **Writing** | Hard to read | Clear, structured | Writes ADRs and RFCs the team uses as references for years |
| **Reading the room** | Misses tension | Surfaces disagreements | Names the elephant; disagrees-and-commits |

## Self-check

- [ ] You shipped the three Phase 12 artifacts (ADR, RFC, postmortem).
- [ ] You have a recurring mentoring relationship.
- [ ] You can quote (or write from scratch) the MADR template.
- [ ] You can quote the five phases of an incident.
- [ ] You can pick consistency models for three different problem
      requirements.
- [ ] You have *changed your mind* at least once during this curriculum
      and can articulate when and why.

## What's next

Nothing in this repo. Now you operate as a Principal: ship the three
artifacts, mentor someone, lead a non-trivial RFC, run an incident, and
keep doing all four for years. The curriculum was scaffolding; the work
is the work.
